# 🏝️ English Island 英語島 — 荒島求生

給第一次準備多益（TOEIC）的入門學習者的荒島求生英語遊戲。你搭郵輪前往國際商務會議途中遇難，漂到一座廢棄的企業度假村荒島，島上的飯店告示、收據、報告、通訊紀錄都是英文——**學會多益常見單字才能活下去，最後修好無線電獲救**。

純前端，不需後端與帳號，進度存在瀏覽器 localStorage。

介面為深色「戰術終端」風格：滿版版面（桌機左側固定生存狀態側欄、右側全寬內容）、線條 SVG 圖示（`src/components/Icon.vue`）、等寬數字、琥珀色訊號主色；地圖點選區域會在右側（手機為底部抽屜）開啟任務簡報。

## 啟動

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 單元測試（遊戲規則與內容檢查）
npm run build    # 產出 dist/，可直接放到任何靜態主機（GitHub Pages / IIS 子路徑皆可）
```

## 求生規則

| 機制 | 說明 |
|---|---|
| 生存數值 | 🍖 飽足、💧 水分、❤️ 生命（0–100） |
| 探索 | 每完成一個英語挑戰 = 探索一次：飽足 -8、水分 -10，並依表現帶回物資 |
| 每日流逝 | 真實時間每過一天：飽足 -25、水分 -30；歸零時每項扣生命 15 |
| 回復 | 吃食物（飽足 +25）、喝水（水分 +30）、敷草藥（生命 +30）；探索時飽足與水分都 ≥ 50 會回復生命 +5 |
| 昏倒 | 生命歸零：數值回到 50，所有物資減半；**學習進度（星星、解鎖）保留** |
| 建造 | 營火、釣竿、集雨桶、庇護所會每天自動幫忙；**求救無線電（⚙️8 + 🪵3）= 獲救通關** |

## 區域與物資

| 區域 | 多益主題 | 單字範例 | 探索獲得 |
|---|---|---|---|
| 🧳 沉船海灘 | 旅行出差 | passenger, luggage, flight… | 🍖 食物 |
| 🏨 廢棄度假飯店 | 飯店與餐廳 | guest, reserve, bill… | 💧 淡水 |
| 🛒 叢林商店 | 購物與消費 | price, discount, receipt… | 🍖 食物 |
| 🗂️ 研究站辦公室 | 辦公室日常 | meeting, schedule, deadline… | 🪵 木材 |
| 🪪 山丘員工宿舍 | 求職與人事 | apply, interview, salary… | 🌿 草藥 |
| 📡 廢棄燈塔通訊室 | 聯絡與通訊 | email, confirm, urgent… | ⚙️ 零件 |

每個區域 4 個挑戰：📖 單字卡、🎯 小測驗（拿 1 星解鎖下一區）、🔤 拼字、💬 句型練習。每拿到一顆新星星額外找到 1 個 ⚙️ 零件。📝 錯題複習答對可獲得 🌿 草藥。

**🔁 每日複習（疊加複習）**：從所有學過區域的單字出 12 題，學越多區題庫越大。答錯過的字優先，其次是最久沒複習的字，所以每天會自動輪到不同的舊單字。每天第一次完成額外取得 🍖+2、💧+2。

## 結構

```
src/data/zones.js        區域與單字
src/data/sentences.js    各區句型與例句
src/data/survival.js     物資、數值、設施的顯示資料
src/logic/progress.js    求生規則：探索、每日流逝、昏倒、建造、解鎖（純函式，有測試）
src/logic/quiz.js        出題、計分、拼字（純函式，有測試）
src/logic/sentence.js    句型填空、排序（純函式，有測試）
src/logic/review.js      每日複習的題庫與挑字順序（純函式，有測試）
src/store/game.js        響應式狀態 + localStorage
src/components/          求生面板、探索結果
src/views/               地圖、區域、單字卡、測驗/複習、拼字、句型、建造
```

數值平衡都集中在 `src/logic/progress.js` 最上方的常數，調整難度只要改那裡。
