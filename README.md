# 🏝️ English Island 英語島 — 荒島求生

給第一次準備多益（TOEIC）的入門學習者的荒島求生英語遊戲。你搭郵輪前往國際商務會議途中遇難，漂到一座廢棄的企業度假村荒島，島上的飯店告示、收據、報告、通訊紀錄都是英文——**學會多益常見單字才能活下去，最後修好無線電獲救**。

純前端，不需後端與帳號，進度存在瀏覽器 localStorage。

介面為深色「戰術終端」風格：滿版版面（桌機左側固定生存狀態側欄、右側全寬內容）、線條 SVG 圖示（`src/components/Icon.vue`）、等寬數字、琥珀色訊號主色。

**🪐 首頁：英語群島星球**——一顆可以拖曳旋轉的星球，表面散布 12 座全英文的島：6 個多益區域、每日漂流瓶、對話咖啡廳、五大長母音、音節切分、錯題怪獸窩、求救無線電塔。拖曳或按「上一座／下一座」（鍵盤左右鍵）轉到想去的島，點島名（或 Enter）登島；右側（手機在下方）列出每座島的星星／熟練度與「出發」。島的順序與位置在 `src/data/planet.js`，投影與旋轉角度計算在 `src/logic/planet.js`。

## 啟動

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 單元測試（遊戲規則與內容檢查）
npm run build    # 產出 dist/，可直接放到任何靜態主機（GitHub Pages / IIS 子路徑皆可）
```

## 求生規則

| 機制 | 說明 |
|---|---|
| 生存數值 | 🍖 飽足、💧 水分、❤️ 生命（0–100） |
| 探索 | 每完成一個英語挑戰 = 探索一次：飽足 -8、水分 -10，並依表現帶回物資 |
| 每日流逝 | 真實時間每過一天：飽足 -25、水分 -30；歸零時每項扣生命 15 |
| 回復 | 吃食物（飽足 +25）、喝水（水分 +30）、敷草藥（生命 +30）；探索時飽足與水分都 ≥ 50 會回復生命 +5 |
| 昏倒 | 生命歸零：數值回到 50，所有物資減半；**學習進度（星星、解鎖）保留** |
| 建造 | 營火、釣竿、集雨桶、庇護所會每天自動幫忙；**求救無線電（⚙️8 + 🪵3）= 獲救通關** |

| 區域 | 多益主題 | 單字範例 | 探索獲得 |
|---|---|---|---|
| 🧳 沉船海灘 | 旅行出差 | passenger, luggage, flight… | 🍖 食物 |
| 🏨 廢棄度假飯店 | 飯店與餐廳 | guest, reserve, bill… | 💧 淡水 |
| 🛒 叢林商店 | 購物與消費 | price, discount, receipt… | 🍖 食物 |
| 🗂️ 研究站辦公室 | 辦公室日常 | meeting, schedule, deadline… | 🪵 木材 |
| 🪪 山丘員工宿舍 | 求職與人事 | apply, interview, salary… | 🌿 草藥 |
| 📡 廢棄燈塔通訊室 | 聯絡與通訊 | email, confirm, urgent… | ⚙️ 零件 |

每個區域 4 個挑戰：📖 單字卡、🎯 小測驗（拿 1 星解鎖下一區）、🔤 拼字、💬 句型練習。每拿到一顆新星星額外找到 1 個 ⚙️ 零件。📝 錯題複習答對可獲得 🌿 草藥。

**🍾 每日單字（每天 5 個新字 + 疊加複習）**：導覽列「每日單字」。每天第一次進來，海浪會沖上 5 個漂流瓶，裝著題庫（`src/data/dailyWords.js`，200 個多益入門字，約 40 天份，與區域單字不重複）依序的下一批新字；沒來的日子不會累積欠帳。打開全部瓶子後進入每日測驗：**今天的 5 個新字全部出 + 10 個舊字**（所有學過的區域單字 + 之前每天發過的字；答錯過的字優先，其次是最久沒複習的字）。題庫用完後改為只複習舊字 12 題。每天第一次完成額外取得 🍖+2、💧+2。要加新字直接加在 `dailyWords.js` 最後即可。

## 💬 對話咖啡廳：情境對話練習

導覽列「情境對話」或星球上的「對話咖啡廳」。8 個多益入門情境：機場報到、飯店入住、餐廳點餐、退換貨、約開會時間、工作面試、電話留言、問路。

- 對方的台詞自動出現並唸出；輪到你時從 3 句中選最合適的回應。
- 錯誤選項仿照多益聽力 Part 2 的陷阱（相似音 passport / passed、重複出現的字、問 Where 答時間、身分或語氣不對），選錯會說明原因並可再選。
- 每句都可點喇叭重聽，可隱藏中文；完成後可「聽完整對話」。
- 第一次就選對的比例換成 1–3 星，存最佳星數在 `english-island-dialogues`（與遊戲存檔分開，不影響求生數值）。
- 新增情境：在 `src/data/dialogues.js` 照現有格式加一段（`them()` 對方台詞、`you(ok(...), no(..., why))` 你的選項）；`tests/dialogue.test.js` 會檢查每輪剛好一個正解、錯誤選項都有說明。

## 🖐️ 自然發音 Phonics：五大長母音

導覽列「自然發音」。以五根手指代表 A E I O U，學「同一個音有好幾種拼法」，遇到陌生單字也能自己拼讀。

| 母音 | IPA | 拼字組合 |
|---|---|---|
| A | /eɪ/ | ai、ay、a_e |
| E | /iː/ | ee、ea、ey、e_e |
| I | /aɪ/ | i_e、ie、igh |
| O | /oʊ/ | o_e、oe、oa、ow |
| U | /juː/ | u_e、ue、ew |
| U | /uː/ | u_e、ue、ew、oo、ui |

- **STEP 1–3**（每個母音的課程頁）：先聽聲音再顯示拼法 → 拼字規則與位置、例外說明 → 單字音素拆解拼讀動畫（正常／慢速、例句、口型舌位、麥克風跟讀）。
- **STEP 4**：長短母音比較（cap / cape…），可聽音辨識。
- **STEP 5**：聽音選字、聽音選母音、選字母組合、填空、陌生單字拼讀、長短音辨識、拖曳分類。答錯一定說明規則與錯誤原因。
- **AI 導師**：規則式、純前端（不需網路或 API 金鑰），依答題紀錄找出易混淆的母音、不熟的拼法，推薦延伸單字與下一步，並自動調整難度（入門／進階／挑戰）。
- **進度**：每個拼字組合熟練度 0–5（答對 +1、答錯 -2）、正確率、錯題、每日複習、弱項加強、綜合測驗。存在 `english-island-phonics`，與遊戲存檔分開，不影響求生數值。
- 語音使用瀏覽器內建 Web Speech：子音以近似音示範（如 buh），不同瀏覽器的聲音會有差異；跟讀需要支援語音辨識的瀏覽器（Chrome / Edge / Safari）。

### ✂️ 音節切分：一元一輔切

自然發音首頁的「音節切分（一元一輔切）」，或直接開 `#/phonics/syllables`。把長單字切成小塊來唸：① 標出元音 V（a e i o u）② 數前兩個元音中間夾幾個輔音 C ③ 下刀 ④ 一段一段唸 ⑤ 合起來。

| 規則 | 型態 | 例字 | 前一段母音 |
|---|---|---|---|
| 複合字 | 小字 \| 小字 | sun·set、air·port | — |
| 兩輔切中間 | VC \| CV | nap·kin、can·cel | 短音（閉音節） |
| 一元一輔切前面 | V \| CV | pa·per、ho·tel | 長音（開音節） |
| 唸不通就切後面 | VC \| V | cam·el、trav·el | 短音 |
| 輔音 + le | C + le | ta·ble、lit·tle | 依前一段開／閉 |

- **示範台**：點例字 → 切開動畫、逐段發音再合起來；另有「好朋友不分開」（ck、sh、th…不切）說明，以及「輸入任何單字看第一刀切哪裡」。
- **🥥 劈椰子切字**：點字母之間的縫把單字劈開，再判斷前一段唸長音或短音；答錯會說明原因（例如先試 V|CV 唸不通要退一步切 VC|V）。每條規則的熟練度存在 phonics 存檔的 `syllables` 課程，可「只練這條」。
- 教材在 `src/data/phonics/syllables.js`（用 `pa|per` 標切點），`tests/syllables.test.js` 會自動檢查每個字真的符合它的規則。

**新增課程**（Short Vowels、Silent E、Vowel Teams、R-controlled、Diphthongs、Blends、Digraphs）：在 `src/data/phonics/` 依 `longVowels.js` 的格式新增資料，到 `index.js` 把該課程改成 `status: 'ready'` 並填入 `data`。路由 `#/phonics/<course-id>` 與練習、進度邏輯會自動支援；`tests/phonics.test.js` 的內容檢查可照樣套用。

## 結構

```
src/data/zones.js        區域與單字
src/data/planet.js       星球上的島嶼清單（順序、顏色、連結）
src/logic/planet.js      星球投影、旋轉到指定島、找正前方的島（純函式，有測試）
src/data/sentences.js    各區句型與例句
src/data/survival.js     物資、數值、設施的顯示資料
src/logic/progress.js    求生規則：探索、每日流逝、昏倒、建造、解鎖（純函式，有測試）
src/logic/quiz.js        出題、計分、拼字（純函式，有測試）
src/logic/sentence.js    句型填空、排序（純函式，有測試）
src/data/dailyWords.js   每日新單字題庫（每天依序發 5 個）
src/data/dialogues.js    情境對話腳本（對方台詞、你的選項與錯誤說明）
src/logic/dialogue.js    對話出題、星數、存檔 sanitize（純函式，有測試）
src/store/talk.js        情境對話進度 + localStorage（獨立存檔）
src/views/talk/          對話咖啡廳列表、對話頁
src/logic/review.js      每日發新字、每日測驗的題庫與挑字順序（純函式，有測試）
src/logic/syllables.js   音節切分：標 V/C、建議切法、出題、答錯解說（純函式，有測試）
src/data/phonics/        自然發音課程註冊表、長母音教材、音素表
src/logic/phonics.js     拼字上色、音素拆解、出題、答題解說（純函式，有測試）
src/logic/phonicsProgress.js  熟練度、自適應出題、AI 導師分析（純函式，有測試）
src/store/phonics.js     自然發音進度 + localStorage（獨立存檔）
src/views/phonics/       五指地圖、課程、長短母音、練習、拖曳分類、進度
src/store/game.js        響應式狀態 + localStorage
src/components/          求生面板、探索結果
src/views/               星球首頁（IslandMap.vue）、區域、單字卡、測驗/複習、拼字、句型、建造
```

數值平衡都集中在 `src/logic/progress.js` 最上方的常數，調整難度只要改那裡。
